01

HTML Fundamental

Membangun kerangka halaman web dari elemen-elemen dasar.

Bayangkan Anda sedang membangun rumah. HTML (HyperText Markup Language) adalah batu bata dan semen penyusun kerangkanya. Tanpa HTML, tidak ada website.

Struktur wajib sebuah website

Setiap halaman web harus memiliki struktur dasar ini agar bisa dibaca oleh browser (seperti Chrome atau Safari):

Kerangka dokumenHTML 
<!doctype html>
<html>
  <head>
    <!-- Informasi untuk browser: judul tab, font, dan lainnya -->
  </head>
  <body>
    <!-- Semua yang Anda lihat di layar ada di sini -->
  </body>
</html>

Elemen penting di dalam <body>

  • Heading: Judul teks dari tingkat 1 hingga 6 (<h1> sampai <h6>).
  • Paragraph: Teks biasa menggunakan <p>.
  • Link: Tautan untuk berpindah halaman, misalnya <a href="url">Klik di sini</a>.
  • Image: Menampilkan gambar dengan <img src="foto.jpg" alt="Deskripsi">.
  • List: Daftar berurutan memakai <ol> atau daftar berpoin memakai <ul>, dengan item <li>.
  • Atribut khusus: class untuk mengelompokkan elemen dan id sebagai identitas unik elemen.
Bayangkan seperti ini

Tag memberi tahu browser jenis kontennya; atribut memberi informasi tambahan pada sebuah elemen.

1 Latihan praktik

Buatlah satu file HTML (index.html). Di dalamnya, buat halaman profil diri Anda yang berisi foto, nama (<h1>), deskripsi singkat (<p>), dan daftar hobi (<ul>).

02

Semantic HTML

Memberi makna pada kerangka dengan tag yang menjelaskan fungsinya.

Di masa lalu, orang membangun web dengan tag generik bernama <div> untuk segalanya. Kini, kita menggunakan Semantic HTML, yaitu tag yang namanya mendeskripsikan fungsinya. Struktur yang jelas membantu browser, mesin pencari, dan teknologi bantu memahami isi halaman.

Bayangkan rumah Anda sekarang sudah memiliki papan nama untuk setiap ruangan:

<header>

Bagian paling atas website, biasanya berisi logo atau pengantar.

<nav>

Menu navigasi, misalnya Beranda, Tentang, dan Kontak.

<main>

Konten utama halaman.

<section>

Bagian spesifik dari konten, misalnya bagian "Layanan Kami".

<article>

Konten mandiri yang bisa berdiri sendiri, seperti postingan blog.

<aside>

Konten tambahan di samping, seperti sidebar.

<footer>

Bagian paling bawah, biasanya berisi hak cipta atau tautan media sosial.

Selain itu, Anda juga mulai mengenal Basic Form (<form>, <input>, <button>) untuk membuat tempat input data seperti kolom pencarian.

2 Latihan praktik

Modifikasi file HTML profil Anda. Masukkan logo dan menu ke dalam <header>, konten profil ke <main>, dan hak cipta di <footer>.

03

CSS Fundamental

Mengecat rumah: mengatur warna, ukuran, dan bentuk elemen HTML.

Kerangka sudah jadi, saatnya mendesain! CSS (Cascading Style Sheets) bertugas mengatur warna, ukuran, dan bentuk elemen HTML Anda.

Cara memanggil CSS

Anda bisa menulis CSS langsung di elemen (inline), di dalam <head> (internal), atau di file terpisah (external), yang sangat direkomendasikan agar gaya mudah dikelola.

Selector dan aturan gaya

Untuk mengubah elemen, panggil namanya menggunakan CSS selector, lalu berikan gaya melalui deklarasi properti dan nilainya:

Contoh aturan CSSCSS 
h1 {
  color: blue; /* Mengubah warna teks */
  background: yellow; /* Mengubah warna latar belakang */
  font-family: Arial, sans-serif; /* Mengubah jenis huruf */
  border: 1px solid black; /* Memberi garis tepi */
  border-radius: 10px; /* Membuat sudut garis membulat */
  width: 500px; /* Mengatur lebar */
  height: 100px; /* Mengatur tinggi */
}
3 Latihan praktik

Buat file style.css dan hubungkan ke HTML Anda. Ubah warna teks halaman profil, ganti jenis hurufnya, dan berikan warna latar belakang yang menarik.

04

CSS Box Model

Memahami ruang yang membentuk ukuran dan jarak setiap elemen.

Ini adalah konsep penting dalam CSS. Di dunia web, semua elemen adalah kotak (box). Bayangkan sebuah lukisan berbingkai:

Border
Padding
Content: teks atau gambar
  1. Content: Kanvas lukisannya, yaitu teks atau gambar.
  2. Padding: Jarak antara kanvas dan bingkai, ruang bernapas di dalam.
  3. Border: Bingkai kayunya itu sendiri.
  4. Margin: Jarak dari bingkai ke elemen lain di sebelahnya, yaitu jarak luar.

Properti penting Box Model

box-sizing

border-box membuat padding dan border ikut dihitung dalam ukuran elemen, sehingga ukurannya lebih mudah dikendalikan.

max-width / min-width

Menentukan batas maksimal atau minimal kelebaran suatu kotak.

display

Menentukan sifat kotak, misalnya apakah elemen berjejer ke samping atau ke bawah.

overflow

Menentukan apa yang terjadi jika isi konten lebih besar dari kotaknya, misalnya disembunyikan atau diberi scroll.

4 Latihan praktik

Buatlah 3 "Card" (kartu profil atau produk) di HTML. Gunakan CSS untuk memberi padding, border, dan margin yang berbeda-beda agar Anda merasakan perbedaannya secara visual.

05

CSS Layout: Float & Clear

Menyusun tata letak klasik dengan elemen yang mengalir ke kiri atau kanan.

Bagaimana cara membuat teks berada di kiri dan gambar di kanan? Sebelum ada teknologi modern, developer web menggunakan teknik Float.

Float bekerja dengan menarik sebuah elemen keluar dari aliran normal dan memaksanya merapat ke kiri (float: left) atau ke kanan (float: right). Elemen teks di bawahnya akan mengalir mengelilingi elemen tersebut, seperti teks mengelilingi gambar di koran.

Masalah Float dan solusinya

Jika sebuah kotak induk berisi anak-anak yang di-float, kotak induk tersebut bisa "kempis" karena tidak menghitung anak-anak itu sebagai bagian dari aliran normal. Akibatnya, tinggi parent tidak mencakup elemen yang di-float.

Solusi

Gunakan perintah clear: both pada elemen setelahnya, atau gunakan teknik clearfix untuk mengembalikan aliran halaman menjadi normal kembali.

06

Responsive Design & Basic UI

Membuat tampilan nyaman dibuka dari ponsel hingga komputer.

Website Anda mungkin terlihat bagus di laptop, tapi bagaimana jika dibuka di HP? Di sinilah Responsive Design masuk.

Senjata utama: Media Queries

Media query memungkinkan kita mengubah desain berdasarkan lebar layar atau breakpoints. Contoh berikut menggunakan desain mobile-first, lalu mengubah sidebar pada layar yang lebih lebar dari 768px:

Layout responsifCSS 
/* Desain default (mobile-first) */
.sidebar {
  width: 100%;
  float: none;
}

/* Jika layar lebih lebar dari 768px (tablet/desktop) */
@media screen and (min-width: 768px) {
  .sidebar {
    width: 30%;
    float: left;
  }
}
Gunakan ukuran yang fleksibel

Gunakan relative units seperti % (persentase) alih-alih px agar gambar dan kotak bisa meregang secara fleksibel.

Basic UI (Antarmuka Pengguna)

Desain yang baik harus nyaman dilihat. Perhatikan hal-hal berikut:

  • Visual Hierarchy: Teks terpenting harus paling besar atau tebal.
  • Spacing: Beri jarak (margin/padding) yang cukup antar elemen. Jangan berdesakan.
  • Interaksi: Tambahkan efek hover (berubah saat disentuh mouse) atau focus pada button agar website terasa lebih hidup.
6 Latihan praktik

Ubah layout dari Pembelajaran 5 menjadi responsif. Di layar HP, Sidebar berada di bawah Content. Di layar Laptop, Sidebar kembali berada di kiri Content.
